### 2.2 Arquivo: `/client/src/lib/utils.ts`

#### 2.2.1 Helper `getDailySociaImage()` (Linhas 8-26)
**Código Adicionado:**
```typescript
/**
 * Retorna uma foto de sócia baseada em rotação diária
 * Garante que a mesma foto seja exibida durante todo o dia
 * @returns Caminho relativo para a imagem da sócia
 */
export function getDailySociaImage(): string {
  const images = ['socia_1.jpeg', 'socia_2.jpeg', 'socia_3.jpeg'];

  // Calcular dia do ano (1-365)
  const now = new Date();
  const start = new Date(now.getFullYear(), 0, 0);
  const diff = now.getTime() - start.getTime();
  const oneDay = 1000 * 60 * 60 * 24;
  const dayOfYear = Math.floor(diff / oneDay);

  // Selecionar imagem baseada no dia
  const index = dayOfYear % images.length;
  return `/images/${images[index]}`;
}
```

**Justificativa:**
- Implementação da **Opção C** do plano (Rotação Diária)
- Vantagens:
  - ✅ Sem flash de carregamento (valor calculado no servidor)
  - ✅ Previsível (mesma imagem durante todo o dia)
  - ✅ Rotação automática (troca a cada dia)
  - ✅ Simples e performático (sem estado React)
- Algoritmo baseado em dia do ano (1-365) % 3 imagens
- Documentação completa com JSDoc
