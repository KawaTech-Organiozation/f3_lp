## 5. Configuracoes

### 5.1 TypeScript (`tsconfig.json`)
```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "jsx": "react-jsx",
    "paths": {
      "@/*": ["./client/src/*"],
      "@shared/*": ["./shared/*"],
      "@server/*": ["./server/*"]
    }
  }
}
```

### 5.2 Vite (`vite.config.ts`)
- Root: `./client`
- Output: `./dist/client`
- Proxy: `/api` -> `localhost:3001`
- Plugins: react, cartographer, devBanner, runtimeErrorModal

### 5.3 Tailwind (`tailwind.config.ts`)
- Content: `./client/**/*.{ts,tsx,html}`
- Theme: CSS variables (HSL)
- Plugins: animate, typography

### 5.4 Drizzle (`drizzle.config.ts`)
- Schema: `./shared/schema.ts`
- Output: `./drizzle`
- Dialect: PostgreSQL
- Credentials: via `DATABASE_URL`

```
┌─────────────────────────────────────────────────────────┐

│  │  Pages  │  │Components│  │  Hooks  │  │   Lib   │    │
│  └────┬────┘  └────┬────┘  └────┬────┘  └────┬────┘    │
│       └────────────┴────────────┴────────────┘          │
│                         │                                │
│                    TanStack Query                        │

                         │ HTTP (fetch)
                         ▼
┌─────────────────────────────────────────────────────────┐

│  ┌─────────┐  ┌─────────┐  ┌─────────┐                 │
```

## 9. Padroes de Design

| Padrao | Uso |
|--------|-----|
| Repository Pattern | `storage.ts` - camada de acesso a dados |
| Component Composition | Radix UI + shadcn/ui |
| Custom Hooks | Encapsulamento de logica reativa |
| Schema First | Zod + Drizzle para validacao end-to-end |
| CSS Variables | Theming com Tailwind |

## 10. Requisitos de Sistema

### Desenvolvimento
- Node.js 18.x ou 20.x
- npm (incluido com Node.js)
- PostgreSQL 14+

### Producao
- Node.js 18+ runtime
- PostgreSQL 14+ database
- Memoria: 512MB+ recomendado
