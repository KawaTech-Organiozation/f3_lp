## 2. TypeScript

### 2.1 Configuracao
- **Target**: ES2020
- **Module**: ESNext
- **Strict mode**: Habilitado
- **JSX**: react-jsx

### 2.2 Convencoes de Tipos
```typescript
// Interfaces para objetos
interface Lead {
  id: number;
  name: string;
}

// Types para unions e derivados
type InsertLead = z.infer<typeof insertLeadSchema>;

// Generics com nomes descritivos
function useQuery<TData, TError>(): QueryResult<TData, TError>
```

### 2.3 Path Aliases
```typescript
// Usar aliases configurados
import { Button } from "@/components/ui/button";      // @/ = client/src
import { schema } from "@shared/schema";              // @shared = shared/
import { db } from "@server/db";                      // @server = server/
```

## 3. React

### 3.1 Estrutura de Componentes
```typescript
// Componente funcional com export default para paginas
export default function LandingPage() {
  return <div>...</div>;
}

// Named export para componentes reutilizaveis
export function LeadForm() {
  return <div>...</div>;
}
```

### 3.2 Hooks
- Prefixo `use` para custom hooks
- Um hook por arquivo em `/hooks/`
- Hooks devem retornar objetos ou tuplas tipadas

```typescript
// hooks/use-leads.ts
export function useCreateLead() {
  return useMutation({
    mutationFn: async (data: InsertLead) => { ... },
  });
}
```

### 3.3 Formularios
- **React Hook Form** para gerenciamento de estado
- **Zod** para validacao (integrado via zodResolver)
- Schema compartilhado com backend (`@shared/schema`)

```typescript
const form = useForm<InsertLead>({
  resolver: zodResolver(insertLeadSchema),
  defaultValues: { name: "", email: "" },
});
```

### 3.4 Estado Global
- **TanStack Query** para dados do servidor
- Evitar Context para dados que mudam frequentemente
- QueryClient configurado em `lib/queryClient.ts`

## 4. Estilizacao

### 4.1 Tailwind CSS
- Usar classes utilitarias diretamente
- Componentes UI via shadcn/ui
- CSS-in-JS NAO utilizado

### 4.2 Funcao `cn()` para Classes Condicionais
```typescript
import { cn } from "@/lib/utils";

<div className={cn(
  "base-classes",
  condition && "conditional-classes"
)} />
```

### 4.3 Variaveis CSS
```css
/* Cores via CSS variables (HSL) */
--primary: 220 80% 50%;
--background: 0 0% 100%;

/* Uso no Tailwind */
bg-primary
text-primary-foreground
```

### 4.4 Responsividade
- Mobile-first (default e mobile)
- Breakpoints: `sm:`, `md:`, `lg:`, `xl:`

```typescript
<div className="px-4 md:px-8 lg:px-12" />
```

## 5. Backend (Express)

### 5.1 Estrutura de Rotas
```typescript
// server/routes.ts
export async function registerRoutes(httpServer: Server, app: Express) {
  app.post("/api/leads", async (req, res) => {
    try {
      const data = insertLeadSchema.parse(req.body);
      const lead = await storage.createLead(data);
      res.status(201).json(lead);
    } catch (error) {
      // Tratamento de erro padronizado
    }
  });
}
```

### 5.2 Validacao
- Sempre usar Zod no server-side
- Schema compartilhado com frontend
- Retornar erros estruturados (400 + detalhes)

### 5.3 Camada de Dados (Repository Pattern)
```typescript
// server/storage.ts
export interface IStorage {
  createLead(lead: InsertLead): Promise<Lead>;
}

export class DatabaseStorage implements IStorage {
  async createLead(data: InsertLead): Promise<Lead> {
    const [lead] = await db.insert(leads).values(data).returning();
    return lead;
  }
}
```

## 6. Banco de Dados (Drizzle ORM)

### 6.1 Definicao de Schema
```typescript
// shared/schema.ts
import { pgTable, text, serial, timestamp } from "drizzle-orm/pg-core";
import { createInsertSchema } from "drizzle-zod";

export const leads = pgTable("leads", {
  id: serial("id").primaryKey(),
  name: text("name").notNull(),
  createdAt: timestamp("created_at").defaultNow(),
});

export const insertLeadSchema = createInsertSchema(leads).omit({
  id: true,
  createdAt: true,
});
```

### 6.2 Convencoes de Nomes
- Tabelas: plural, snake_case (`leads`, `user_sessions`)
- Colunas: snake_case (`created_at`, `city_state`)
- Tipos TS: PascalCase (`Lead`, `InsertLead`)

## 8. Imports

### 8.1 Ordem de Imports
1. Bibliotecas externas (react, framer-motion)
2. Componentes UI (@/components/ui/*)
3. Componentes locais (@/components/*)
4. Hooks (@/hooks/*)
5. Utilitarios (@/lib/*)
6. Tipos e schemas (@shared/*)

### 8.2 Exemplo
```typescript
// 1. Externos
import { useForm } from "react-hook-form";
import { zodResolver } from "@hookform/resolvers/zod";
import { motion } from "framer-motion";

// 2. UI
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";

// 3. Componentes locais
import { LeadForm } from "@/components/LeadForm";

// 4. Hooks
import { useCreateLead } from "@/hooks/use-leads";

// 5. Schemas
import { insertLeadSchema, type InsertLead } from "@shared/schema";
```

## 9. Nomenclatura

| Tipo | Convencao | Exemplo |
|------|-----------|---------|
| Componentes | PascalCase | `LeadForm.tsx` |
| Hooks | camelCase com prefixo `use` | `use-leads.ts` |
| Utilitarios | camelCase | `queryClient.ts` |
| Tipos/Interfaces | PascalCase | `InsertLead` |
| Constantes | UPPER_SNAKE_CASE | `API_BASE_URL` |
| Funcoes | camelCase | `createLead()` |
| Variaveis | camelCase | `isPending` |

## 10. Git e Commits

### 10.1 Conventional Commits
```
tipo(escopo): descricao curta

[corpo opcional]

[rodape opcional]
```

### 10.2 Tipos Permitidos
- `feat`: Nova funcionalidade
- `fix`: Correcao de bug
- `docs`: Documentacao
- `style`: Formatacao (sem mudanca de logica)
- `refactor`: Refatoracao
- `test`: Testes
- `chore`: Manutencao

### 10.3 Exemplos
```
feat(leads): add phone validation to form
fix(api): handle null values in lead creation
docs(readme): update installation instructions
```
